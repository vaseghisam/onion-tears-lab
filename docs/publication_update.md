# Final manuscript integration

Version 1.1.0, 27 September 2026.

The author supplied the final manuscript as `Why_Onions_Make_Us_Cry_TK.md`. Its exact received text is retained in `provenance/author_manuscript_2026-09-27.md`. That historical copy contains the duplicate figure numbers and external image links present at receipt; the current reading files are `article.md` and `article_tk.md` at the repository root.

## Changes made for production

The article's scientific prose, equations, quantities, argument, title and subtitle are preserved. Production changes normalize the figure numbers and image paths, unescape numbered citations, put each display equation on one source line, separate image and caption paragraphs, and remove redundant bold markup within the main heading. The painting credit supplied as image alternative text is also made visible as a caption, with a link to the museum's description. Figure-caption separators use periods consistently. Alternative text describes each image instead of repeating a generic filename. The TK export uses conservative punctuation and asterisk emphasis.

The previously agreed private-repository access statement is inserted immediately before the references. It is the only new prose paragraph. This packaging operation does not create a repository, publish files, change repository visibility or grant access.
