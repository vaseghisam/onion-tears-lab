# Work and review responsibilities

| Role | Work produced | Review responsibility |
| --- | --- | --- |
| Research | Primary-source review, claim ledger, references, search record | Distinguish chemical, droplet, exposure, and physiological endpoints |
| Modelling | Equations, Python implementation, parameter provenance, saved results, supplement | State assumptions and analytical limits |
| Numerical QA | Independent tests and numerical review | Check mathematics, conservation, integration, limiting cases, and reported values |
| Visual production | Diagrams, static figures, MP4, GIF, plotting source | Generate plots from saved results and inspect readability |
| Scientific review | Claim, interpretation, and caption audit | Identify unsupported conclusions and mismatched evidence |
| Lead editor | Article, integration, package documentation and release checks | Resolve findings, check final text against results, and verify complete reproduction |

Production and review were assigned to separate agents. The review reports identify their scope and any limitations. Scientific claims are checked against primary publications; numerical verification checks the stated model and does not establish its accuracy in a real kitchen.

The model is frozen before final article numbers and visuals are accepted. Corrections to equations, inputs, or interpretation require the affected result, caption, and prose to be checked again. The final clean-extraction check tests the instructions a reader will use.
